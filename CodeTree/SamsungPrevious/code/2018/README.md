### 삼성 2018 상반기 오전 1번 문제
## [이상한 체스](https://www.codetree.ai/ko/frequent-problems/samsung-sw/problems/odd-chess/description)

### 문제 풀이
각 체스 말 4종류에 대해 이동할 수 있는 방향을 저장한다 (moving)

한 방향에 움직이는 1칸 위치를 각각 X, Y로 저장한다

n, m 값과 체스 판 위치를 board에 저장한다

체스 위치를 chessPieces에 Position 클래스를 사용해서 저장한다

함수를 호출하여서 각 체스 말 위치에 대해 이동할 수 있는 1가지 경우의 수에 대해 이동할 수 있는 0번째 칸이 있으면 visited로 저장한다

만약 visited에서 다른 말이 방문하지 않는 빈칸 위치라면 전체 빈칸 개수인 count에서 -1을 한다

함수를 호출하여서 다음 말의 경우의 수를 확인하게 한다

말에 대해 모든 말들에 대해 확인을 했으면 남은 count를 확인해서 minCount와 비교하여 업데이트 한다

다시 재귀가 돌아오면 수행했던 경우의 수에 대해 초기화를 하고, 다음 경우의 방향에 대해 시도한다


### 시간복잡도 && 공간복잡도

#### 시간복잡도

* P개의 체스말이 존재할 때 1개의 말에 대해 최대 4개의 방향에 대해 확인을 해야 하므로 4 x 4 x 4.... 를 P 번 반복하는 재귀이므로 4^P 번

* 1개의 방향에 대해 최대 n or m 칸을 확인해야 한다

* 이때 1개의 방향에 대해 최악일 때는 5번 말을 기준으로 상하좌우를 모두 확인하기 때문에 n+m 이다

* 그러므로 Big-O의 계산법에 따라 O(4^P x (n+m)) 이 된다

#### 공간복잡도
* 최악의 공간에 대해 board가 n x m 의 크기이므로 Big-O 계산법에 따라 O(nm) 이다

### 문제 설명

N × M 크기의 격자판 위에는 여러 개의 체스 말과 벽이 놓여 있다.

체스 말은 종류에 따라 감시할 수 있는 방향이 다르며, 각 체스 말의 방향을 회전시킬 수 있다. 체스 말은 자신이 바라보는 방향으로 벽을 만나기 전까지 계속 감시할 수 있다.

단, 다른 체스 말은 감시를 막지 않는다. 즉, 감시 방향에 다른 체스 말이 있어도 그 뒤쪽 칸까지 계속 감시할 수 있다.

각 체스 말의 방향을 적절히 정했을 때, 어떤 체스 말에게도 감시되지 않는 빈 칸의 개수를 최소로 만들어야 한다.

체스 말의 종류별 감시 방향은 다음과 같다.

* 1번 체스 말: 상, 하, 좌, 우 중 한 방향
* 2번 체스 말: 상·하 또는 좌·우
* 3번 체스 말: 서로 직각인 두 방향
* 4번 체스 말: 한 방향을 제외한 세 방향
* 5번 체스 말: 상, 하, 좌, 우 모든 방향

벽은 `6`으로 표시되며, 체스 말의 감시는 벽을 통과할 수 없다.

### 입력

첫 번째 줄에 격자의 행의 수 `N`과 열의 수 `M`이 공백을 두고 주어진다.

이후 `N`개의 줄에 걸쳐 각 행의 상태가 주어진다.

각 칸에는 다음 중 하나의 값이 주어진다.

* `0`: 빈 칸
* `1` ~ `5`: 해당 번호의 체스 말
* `6`: 벽

### 제한 조건

1 <= n,m <= 8
체스 말의 개수는 8개를 넘지 않는다.

### 출력

모든 체스 말의 방향을 적절히 설정했을 때, 감시되지 않는 빈 칸의 최소 개수를 출력한다.
